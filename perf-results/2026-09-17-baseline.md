|-------------------------|-----------|----------|------------------------------|
| 1k  features × 5  expr  |     6.40  |    7.28  | 5,005                        |

### Scaling proof (confirms per-expression cloning)

| Ratio                              | Observed | Expected if per-expression | Expected if per-feature |
|------------------------------------|----------|---------------------------|------------------------|
| mean(10k × 15) / mean(10k × 5)    |    2.63× |                      3.0× |                    1.0× |
| mean(10k × 10) / mean(10k × 5)    |    1.77× |                      2.0× |                    1.0× |

Ratios track linearly with expression count → consistent with `cloneDeep` being called per expression, not per feature.

### What this means

Call chain: `evalSimpleLayer` → `evalSimpleLayerFeature` per feature → `evalLayerAppearances` →
`recursiveValEval` → `evalExpression` (×exprCount per feature) → `cloneDeep(feature)`.

Total `cloneDeep` calls = (features + 1) × expressions (the +1 is the layer-level appearance evaluation).
For a 35k-feature layer with 10 style expressions: **350,010 deep clones per render cycle**.

After **P1 fix** (hoist clone to feature level): 35,001 clones → **~10× fewer clones**.
Expected mean improvement for `35k × 10` (Amdahl, cloneDeep is ~65–70% of runtime): ~417ms → **~165–190ms**.

## MVT reference stability (`pnpm test mvt.reference`)

| Metric                                       | Baseline | Expected after P2a fix |
|----------------------------------------------|----------|------------------------|
| `extractSimpleLayer` same ref on repeat call | NO       | YES                    |
| Provider constructions in 10 re-renders      | 10       | 0                      |

### What this means

`extractSimpleLayer` calls `toPlainObject = cloneDeep(obj)` on every invocation.
`useMVT` (mvt.ts:19) calls it on every render and puts the result in `useMemo`'s dep array.
Since the reference changes every render, `useMemo` never caches → `MVTImageryProvider` is
reconstructed on every render, even when no props changed.

After **P2a fix**: stabilize the reference (e.g. deep-equal comparison or JSON-stable serialization)
so `useMemo` actually caches the provider.
